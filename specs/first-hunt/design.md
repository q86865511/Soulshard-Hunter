# R33 設計與接點

採獨立單人 first_hunt 模式，從出擊面板與廣場魂火台進入。三名借用英雄使用獨立 sprite ID；保留既有角色、皮膚及標準模式。場內美術沿用程序像素管線，無新增外部資產。

- `content/first_hunt.js`：角色文案、三選一資料、手工地圖、存檔容錯與印記／重建純函式。
- `BALANCE.FIRST_HUNT`：所有新玩法數值與時間點。
- `run/first_hunt.js`：單人試煉能力、敵潮、守火者的落印／十字裂擊預警、HUD、成長選擇及結算。
- `hub/first_hunt.js`：三角色入口、重建進度、消耗印記、場景裝飾更新。
- `state.js`：試煉不套用一般 meta 數值；結算先分流，不增加正常戰績、關卡進度、金幣或排行榜紀錄。

## 節奏

0–20 秒：非阻塞操作提示與代表能力。20 秒：第一次祝福三選一。65 秒：第二次祝福。90 秒：敵潮加壓。150 秒：清場並迎戰守火者，50% 生命切第二階段。三分鐘是目標體驗長度，首領不會因計時自動死亡或強制判勝。

經驗升級在初獵自動強化起始武器，避免正常升級卡與兩次教學選擇互相阻塞。商店、隱藏房與隨機事件在試煉不啟用。

## 成長與相容

`META.firstHunt={completed:string[],restored:number,attempts:number}` 為新增的可選欄位；讀取時白名單去重與限制範圍。每名英雄第一次非作弊通關給一枚印記，最多三枚。重建依序花一枚：營火（僅初獵拾取 +12）、旗幟（永久解鎖烈焰術士）、戰利品（永久解鎖晶岩守衛）。沒有金幣獎勵，不能重玩刷取收益。

共享的 World 只增加可選拾取回呼；合作不會建立試煉狀態、不更動協定。既有戰鬥與結算入口以 mode guard 分流。
