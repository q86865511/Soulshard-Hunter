# 設計

使用者已授權正式實作、必要 src／連線協定變更，以及 Dockerfile、compose、deploy.yml、.dockerignore 的本機設定修改與驗證。沒有發布或部署授權；遊戲數值及存檔格式不變。

每個房間一個 Node 子程序，隔離全域 META、內容、場景與 RNG。共用 bootstrap 載入完整遊戲內容；headless 環境只提供視覺／音效介面，真實 runScene 以固定 1/120 秒運作。CoopHost 注入傳輸，原房主也改用網路輸入，但保留原角色加成、升級與圖鑑規則。

主程序負責 JWT／角色綁定、房間容量、輸入限流、runId／seq／choiceId、重連與持久化。暫時斷線角色仍受世界傷害；永久離房才移出活動角色。原房主離開仍可維持隊伍，最後離房先結算再回收程序。不得用重連回血或復活，也不得以輸入頻率加速世界。

原房主的已同步雲存檔是開局進度來源；依現有定義驗證數值範圍，伺服器重算屬性。離線進度本身不宣稱可驗真。原有存檔 v2 與欄位保持相容；唯一收據放獨立 authority_results 表。結算 CAS 防止覆蓋較新存檔，收據防止重複寫入；衝突結果保留供後續處理，不自動合併。

完整責任、故障規則及驗證限制見 docs/architecture/SERVER_AUTHORITY_R32.md。驗收以 requirements.md 為準。
