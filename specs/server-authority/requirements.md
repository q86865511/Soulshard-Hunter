# 伺服器權威合作模擬（R32）
使用者已授權正式實作及必要 src／連線協定調整；遊戲數值與存檔格式不變。
- R1：伺服器擁有真實 World/Player/Enemy、完整內容、固定 1/120 秒模擬；所有客戶端只呈現快照與送輸入。
- R2：房間獨立程序，僅允許由連線身分綁定的有界、有限、遞增序號輸入；重播／跨房／觀戰／偽造快照和結算無效。訊息頻率不能加速模擬。
- R3：保留既有合作玩法數值、房主與訪客的初始能力及升級差異。進度從既有雲存檔讀取並驗證合法範圍，不接受傳入戰鬥屬性。離線進度來源仍可被使用者編輯，須明確揭露此信任限制。
- R4：房主退出不終止其他玩家的模擬；在仍進行的對局中，斷線 20 秒內可接回同一角色及其最新血量／死亡狀態；過期／空房／超載／程序故障可回收，不留下背景模擬。
- R5：伺服器產生 runId 與結算；不可由客戶端送任意結果冒充權威對局，重複交付不得重複入帳；勝負與保存確認分開，慢寫入不得偽裝成模擬斷線。存檔 v2 及既有欄位結構不變。
- R6：新協定明確協商；舊客戶端收到可理解的更新提示，不能靜默退回不可信主機。
- R7：共用模擬與瀏覽器固定情境比較（移動／碰撞／傷害／XP／升級／勝負），驗證完整登錄與既有測試；目標平台容量未實測就不得宣稱部署容量。
- R8：A/C 批次原 worktree 保持來源與 HEAD 不變；不部署、不 push／PR／merge。
