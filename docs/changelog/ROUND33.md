# ROUND33 / V2.2 — 初獵：重燃魂火

日期：2026-10-23。目標是三名代表角色、一個地區、一隻 Boss、前三分鐘與回城成長的可玩展示。使用者已授權檢查後 commit、push 並部署至正式站。版本升為 V2.2；正式部署結果以本次 main push 的 GitHub Actions 紀錄及站點驗證為準。

## 玩家可見的更新

- 出擊面板新增初獵入口，廣場另有可按 E 互動的魂火台。
- 魂晶獵手、烈焰術士、晶岩守衛可免費借用，不花金幣、不改原選角。三名角色使用獨立程序像素造型；分別以拾取、擊殺、近身／受傷蓄能，滿格自動施放魂晶共鳴、餘燼連鎖、晶岩反震。能力條、發動提示與音效可辨識。
- 幽影地穴新增獨立魂火祭壇競技場：中央通道、斑塊地表、破碎祭壇、石棺、燭台、獵旗與局部光源。私有守火者定義不加入正式敵人／隨機首領池，既有 registry 計數不變。
- 20／65 秒提供暫停的三選一祝福；經驗升級自動強化起始武器。淬鍊武器超過等級上限的部分轉為傷害，避免選到無效獎勵。
- 90 秒敵潮加壓；150 秒召喚守火者。第一階段落印光圈、50% 生命後十字裂擊，完整受擊區域與中心光束皆預警。少量有上限的增援讓收集／擊殺能力在首領戰仍能運作。
- 擊敗首領立即結算，首領戰不因三分鐘計時自動判勝。每位角色首次非作弊通關得一枚重建印記；重玩、重複結算、死亡、放棄及開發者強制通關不重複發獎。
- 回城消耗印記依序重燃營火（僅初獵拾取 +12）、掛起旗幟（永久解鎖烈焰術士）、展示頭盔戰利品（永久解鎖晶岩守衛）。廣場有可見改變，完成後可直接前往正式狩獵。

## 技術界線

規格：[requirements](../../specs/first-hunt/requirements.md)、[design](../../specs/first-hunt/design.md)、[tasks](../../specs/first-hunt/tasks.md)。所有試煉玩法數值集中在 BALANCE.FIRST_HUNT。

`META.firstHunt` 為可選新增欄位，讀取時限縮合法英雄、去重與限制進度；舊存檔不需升版即可使用。試煉不套用天賦／設施／武器鍛造數值；實際用過的武器仍會進入既有圖鑑。結算獨立，不增加金幣、正式戰績、公會聲望、正式關卡解鎖或排行榜結果。

共享 World 新增可選 XP 拾取回呼及光束壽命參數（既有預設仍為 0.14）；多人協定未改。合作不建立初獵狀態。原 20 分鐘、劇情、每日、無盡模式保留。

## 驗證與限制

- `npm --prefix test run test:first-hunt`：10 項單元測試（含 4 項快取回歸）、40 項真實瀏覽器功能檢查；含三角色能力、兩次選擇、150 秒首領、兩階段可閃避預警、完整結算／回城重建、舊存檔重載、排行榜隔離、滿級獎勵轉換及版本日誌一致性。
- 連續 120Hz 情境遍歷三名角色的前三分鐘；為分支覆蓋而保持生命，不能解讀為真人通關率或難度評估。
- 1280×720／1920×1080 版面及粒子關閉截圖位於本機 `.pipeline/first-hunt/`，不提交測試畫面。檢查發現並修正首領出生出框、營火接近 NPC，以及十字預警窄於實際受擊範圍。
- 既有前端 59 條 smoke、權威伺服器整套（含 270 世界啟動）、10 個瀏覽器／Node 一致性 checkpoint 與 13 項雙瀏覽器合作流程已通過。實際執行環境為 Node 24.15.0；CI 仍使用 Node 22。
- 新初獵測試加入 frontend-test CI。最終執行結果見本輪回報，不以既有歷史測試代替本輪驗證。

這是可玩的第一版；程序像素美術與平衡仍可依真人試玩收斂，尚無留存、購買意願或商業成效的實測結論。

## 發布檢查

對照 FH-01～09 檢視初獵入口、借用角色、能力與預警、獎勵防重領、正常模式隔離及舊存檔相容性，未發現阻擋發布的玩法問題。發布準備補上 V2.2 標題版本、玩家更新日誌與本文的發布授權資訊。

首次部署後，隔離瀏覽器 40 項檢查通過、24 個 JS 與 commit 雜湊一致，但既有瀏覽器仍顯示 V2.1。線上程式檔的快取標頭為 max-age=14400；原 worker 的 fetch(req) 仍可能沿用 HTTP／CDN 舊物件。跟進修正為版本化 worker、啟動模組前等待新 worker，以及程式請求的版本查詢參數與 no-store；保留離線模組回退及音樂／圖片 cache-first，僅輪替 Cache Storage、不觸碰玩家存檔。另加 4 項 Service Worker 回歸測試。

部署後使用 `node test/first-hunt-browser.mjs --production`，以隔離瀏覽器直接載入正式站重跑初獵檢查；阻擋全部 `/api/` 請求與 Service Worker，僅在暫存瀏覽器設定檔建立試玩進度，不寫入正式帳號、排行榜或資料庫。
